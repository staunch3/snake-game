# 贪吃蛇 · Snake

一个零依赖的浏览器贪吃蛇，全部实现都在单个 `index.html` 里。双击打开就能玩，不用装任何东西。

## 玩法

吃到红色食物，蛇身加长、得分 +10，同时速度略微加快。撞到墙壁或自己的身体就结束。最高分保存在浏览器本地（`localStorage`），下次打开还在。

## 操作

| 操作 | 按键 |
| --- | --- |
| 移动 | `↑` `↓` `←` `→` 或 `W` `A` `S` `D` |
| 开始 / 暂停 / 继续 | `空格` 或 `Enter` |
| 手机 | 在棋盘上滑动；轻点开始 |

手感上做了两点处理：按键进入一个小队列（最多缓存 3 个转向），快速连打不会丢操作；同时禁止 180° 掉头，所以不会因为手快而瞬间自杀。

## 实现要点

- **Canvas 2D 渲染**，按 `devicePixelRatio` 缩放，高分屏不发虚；棋盘用 `aspect-ratio` 自适应，手机上也是正方形。
- **定步长逻辑 + 插值渲染**：游戏以固定间隔（150ms 起，最快 70ms）推进一格，但渲染在相邻两格之间做线性插值，所以移动是顺滑的而不是一格一格跳。
- **单文件、无构建、无依赖**，直接用浏览器原生能力。

## 本地运行

直接打开文件即可：

```bash
start index.html        # Windows
```

想跑在本地服务器上（例如测试移动端访问）：

```bash
python -m http.server 8000
# 然后访问 http://localhost:8000
```
